## Rules

- Compounds: **1–3 RIR**.
- Isolations: **0–2 RIR**.
- Add reps first; add load when the top of the rep range is reached with target RIR and stable technique.
- Prefer pain-free variants. Do not force movements that provoke shoulder or tendon pain.
- If systemic post-session fatigue is excessive, remove auxiliary volume first rather than making the important sets less effective.
- Direct biceps volume starts deliberately low because elbow/biceps tendons are the recurring limiter.
